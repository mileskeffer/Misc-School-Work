ANSWER KEY AND EXPLANATIONS
===========================

1.  B - SquareAdapter publicly implements Square and contains a LegacyRectangle
        member. The finished program uses composition rather than the reference
        class adapter's private inheritance from LegacyRectangle.
2.  D - size() reads the rectangle getters and subtracts the left x-coordinate
        from the right x-coordinate. It does not calculate area or cache a size.
3.  A - resize() preserves x and y, then calls move(x, y, x + newSize, y + newSize).
        The hypothetical coordinates therefore become (2, 3) and (6, 7).
4.  C - The method checks newSize <= 0 and returns before move(). This differs
        from main's invalid-input handling, which prints an error and exits.
5.  B - Virtual dispatch selects behavior from the current state. Passing this
        supplies the Process context that the state can modify.
6.  D - Running::block() sets state_ to the address returned by blockedState().
7.  A - Ready overrides dispatch() only. Its inherited block() has an empty body.
8.  C - nextId_ is shared across instances. Post-increment uses the current value
        for this object's ID and then advances the counter for later constructions.
9.  B - The scheduler moves pointers, preserving each Process and its state members.
        pop() removes a pointer entry; explicit delete is still needed on exit.
10. D - The || condition continues when either queue has work. It becomes false
        only when both empty() checks are true.
11. A - The initializer is adaptee_(0, 0, size, size). These bounds produce a side
        length of 3 because the drawing loops exclude the bottom-right bounds.
12. C - draw() delegates to oldDraw(). Starting at (0, 0), three rows and three
        columns print nine stars; the square is filled, not hollow.
13. B - main rejects failed extraction or nonpositive input before constructing
        the adapter. It prints the positive-integer message and returns 1.
14. D - The coordinates are the source of truth for size(). After move() changes
        the bottom-right x-coordinate, the getter subtraction reflects the change.
15. A - adaptee_ is a value member, not a pointer allocated with new. Normal member
        destruction releases it without a custom delete operation.
16. C - All three operations are pure virtual in Square. The concrete adapter
        provides the implementations, allowing use through the target interface.
17. B - Process initializes state_ with &ready_ after constructing its state members.
18. D - ready_, running_, and blocked_ are Process members. The state_ pointer
        selects among them; transitions do not allocate or delete State objects.
19. A - Ready -> Running -> Blocked; dispatch while blocked does nothing; unblock
        returns to Ready; suspend while ready also does nothing.
20. C - The scheduler pops process 1, changes it back to ready, and pushes its
        pointer at the back. The other ready processes keep their relative order.
21. B - Process 1 is removed from readyQueue and appended to blockedQueue. The
        older blocked process 4 stays at the front.
22. D - Only the blocked front is popped. Its state changes to ready and its
        pointer joins the back of readyQueue.
23. A - The unblocking step follows the dispatch/action step in the same iteration.
        With no earlier blocked process, the newly blocked one is already the front.
24. C - The unblocking check is outside the if/else for readyQueue. This permits
        progress even when every surviving process is blocked.
25. B - Random choices control repeated transitions and waiting iterations. The
        code sets no fixed iteration limit or predetermined schedule.
26. D - A false left operand of && prevents evaluation of its right operand. No
        random number is consumed by this expression when blockedQueue is empty.
27. A - After dispatch, action == 0 reports exit and deletes the Process pointer
        already popped from readyQueue. Only Ready, Running, and Blocked exist.
28. C - nextId_ counts constructions. Deleting an object does not rewind it.
29. B - Process/State code maintains the state pointer. main separately pops and
        pushes queue entries so container membership agrees with those transitions.
30. D - report() writes "process ", the ID, and " is "; Ready::report() adds
        lowercase "ready". The older reference transcript uses different wording.
