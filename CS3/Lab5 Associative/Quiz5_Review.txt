ANSWER KEY AND SHORT EXPLANATIONS
=================================

1.  B - The map key is a unique Student; its mapped value is a list of courses.
2.  B - std::map uses its ordering relation. Equivalent keys compare false both ways.
3.  B - map::operator[] inserts a value-initialized mapped value when the key is absent.
4.  B - The find check adds a course only when it is not already in the list.
5.  A - Course names are appended in command-line order: cs1, cs2, cs3, then cs4.
6.  B - Erasing by key removes the one map element, including its complete course list.
7.  A - argv[argc - 1] is intentionally processed later as the dropout roster.
8.  B - Iteration over a map follows key order, which Student::operator< defines.
9.  B - The set contains the remaining map keys once each and prints names only.
10. C - courseName() removes both the directory portion and the final extension.
11. C - Students are ordered by first name, with last name breaking a first-name tie.
12. C - argc must be at least 3: executable, one course roster, and dropout roster.
13. D - The loop body runs only after both formatted string extractions succeed.
14. C - The code prints "Unable to open <filename>" to cerr, then calls exit().
15. B - map and set derive both sorted order and equivalence from operator<.
16. A - The constructor receives copies by value and moves those parameters into members.
17. B - The code prints ':' and then the first course with no intervening space.
18. B - Alan Wood and Anne Clark are dropouts; Andrew Turner is the first remaining key.
19. A - There are 44 unique roster names and all 9 listed dropouts occur among them.
20. D - The dropout erase removes the student's entire entry before either final view prints.
